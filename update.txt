2. БЛОК "КТО"
==================================================

Добавить выбор типа путешествия:

- Один
- Пара
- Семья
- Друзья
- Группа

После выбора типа путешествия интерфейс должен динамически показывать необходимые поля.


--------------------------------------------------
2.1 ОДИН
--------------------------------------------------

Автоматически:

adults = 1
children = 0

Не показывать пользователю лишние поля.


--------------------------------------------------
2.2 ПАРА
--------------------------------------------------

Автоматически:

adults = 2
children = 0

Количество взрослых НЕ спрашивать.

Система автоматически понимает, что "Пара" = 2 взрослых.


--------------------------------------------------
2.3 СЕМЬЯ
--------------------------------------------------

Показать:

Количество взрослых
Количество детей

Например:

Взрослые: [-] 2 [+]
Дети: [-] 2 [+]


--------------------------------------------------
2.4 ДРУЗЬЯ
--------------------------------------------------

Показать:

Количество человек

Все участники считаются отдельными плательщиками по умолчанию.

Например:

4 friends
→ 4 people
→ стоимость / 4


--------------------------------------------------
2.5 ГРУППА
--------------------------------------------------

Показать:

Количество взрослых
Количество детей

Система должна автоматически рассчитывать:

totalPeople = adults + children

3. ЕДИНАЯ МОДЕЛЬ ПУТЕШЕСТВЕННИКОВ
==================================================

Создать единый объект:

travelers:
{
  type: "solo" | "couple" | "family" | "friends" | "group",
  adults: number,
  children: number,
  total: number
}

Правила:

solo:
adults = 1
children = 0

couple:
adults = 2
children = 0

family:
adults = user input
children = user input

friends:
adults = user input
children = 0

group:
adults = user input
children = user input

total = adults + children

Не дублировать эту бизнес-логику в разных компонентах.

Использовать единый источник истины.

==================================================

Минимум:

totalDays >= 1

→ family-friendly activities

IF children > 0
→ учитывать детей

IF travelers = friends
→ shared cost per person

IF travelers = couple
→ 2 adults automatically

IF budget <= $200
→ prioritize nearby / low-cost trips
[8/14/26 9:03 PM] Артём: IF pace = relaxed
→ fewer activities

IF pace = intensive
→ more activities

IF activeDays < totalDays
→ create rest days

IF group is large
→ recommend suitable transfer vehicles

IF selected service causes budget overrun
→ show warning and alternatives

IF destination = Tashkent Region
→ show nearby low-budget mountain/day-trip options

29. ВАЛИДАЦИЯ
==================================================

Обязательно:

- adults >= 1 для family/group;
- children >= 0;
- totalDays >= 1;
- activeDays >= 0;
- activeDays <= totalDays;
- passengers = travelers.total;
- нельзя выбрать автомобиль, если он не вмещает группу;
- нельзя выбрать номер с недостаточной вместимостью без предложения дополнительного номера;
- выбранный транспорт должен соответствовать количеству пассажиров;
- budget должен быть выбран.
