# DiyorAI — MVP туристического помощника (TravelTech, Кейс B)

Веб-приложение: единый цифровой помощник туриста — маршрут, проверка фактов, поиск гида.
Реализует MVP без LLM API: все три модуля работают на детерминированных алгоритмах
(скоринг, fuzzy text matching, nearest-neighbor маршрутизация). Подробности архитектуры и
обоснование решений — в `implementation_plan_tourism_assistant.md` в корне архива.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:3000

Продакшн-сборка:

```bash
npm run build
npm run start
```

## Структура

```
src/
  data/            — сид-данные (объекты, факты, гиды) — открытые источники, JSON вместо БД для портативности MVP
  lib/
    types.ts       — общие типы
    textMatch.ts   — fuzzy-сопоставление текста без LLM (word overlap + триграммы)
    tripPlanner.ts — скоринг объектов, nearest-neighbor маршрутизация, скоринг гидов
  pages/
    index.tsx      — форма предпочтений (регион, интересы, дни, темп, соло)
    trip.tsx        — построенный маршрут: карта + список по дням
    verify.tsx       — проверка фактов об объекте
    guides.tsx        — каталог и подбор гидов
    api/             — эндпоинты /plan-trip, /verify, /guides, /objects
  components/       — Layout, карта (Leaflet), чипы интересов, SVG-паттерн
```

## Важные заметки перед продакшеном

- **Данные о гидах — demo-данные**, явно помечены в интерфейсе (`isDemoData: true`).
  Перед реальным использованием заменить на данные от Комитета по туризму через `/api/guides`.
- **Объекты и факты** — куратированный вручную набор по Самарканду, Бухаре, Хиве и Ташкенту
  на основе открытых данных (Wikipedia/Wikidata). Для продакшена — заменить на ETL-импорт
  из Overpass API (OSM) и Wikidata SPARQL, как описано в implementation plan.
- **Хранилище** — сейчас JSON-файлы вместо PostgreSQL/PostGIS для простоты локального запуска.
  Слой доступа к данным вынесен в `src/lib/tripPlanner.ts`, чтобы замена на реальную БД
  не затронула API-роуты и фронтенд.
- **Маршрутизация** — расстояния считаются по прямой (haversine), а не по реальным дорогам.
  Для точного времени в пути — подключить self-hosted OSRM (см. implementation plan, раздел «Риски»).
